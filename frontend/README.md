# React UI (LeafScope)

This folder contains the React frontend for the Plant Disease Detection platform.

## Run

```bash
npm install
npm run dev
```

App URL: http://localhost:5173

## Backend URL

By default, the frontend calls:

- http://127.0.0.1:8000

Override using `.env`:

```bash
VITE_API_BASE_URL=http://127.0.0.1:8000
```

You can copy `.env.example` to `.env` and update the value as needed.
